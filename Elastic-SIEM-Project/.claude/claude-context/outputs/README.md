# Outputs del Council

Acá se guardan los **entregables** del flujo del Council: auditorías, reglas,
reportes y triage. Una carpeta por categoría para que los outputs se acumulen
ordenados.

| Carpeta / archivo | Qué contiene |
|-------------------|--------------|
| `auditoria-y-mejoras-2026-06-11.md` | Auditoría del Council + changelog completo de mejoras aplicadas. |
| `detection-rules/` | Reglas de detección como código (JSON/NDJSON para importar en Elastic). |
| `incident-reports/` | Reportes técnicos de incidentes para el equipo / gerencia. |
| `alerts-triage/` | Análisis de falsos positivos y alertas validadas. |
